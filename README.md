# 聽句 Web（TingJu Web）

英文聽讀練習網頁版 —— 貼上文章就自動分句、翻中文，逐句朗讀與聽寫。

純前端單檔，**不需要伺服器**；發音用手機／電腦內建的語音引擎（Web Speech API），翻譯走 Google 翻譯免費端點。

原專案：[Pi3-l22/TingJu](https://github.com/Pi3-l22/TingJu)（AGPL-3.0）。本版為行動裝置用的輕量重寫版，致敬原作的聽句流程。

## 用法
1. 開 <https://tonyv922.github.io/tingju-web/>
2. 手機：Safari／Chrome →「加入主畫面」，之後像 App 一樣開
3. 貼英文文章 →「產生聽句」→ 逐句聽、聽寫、標星號複習
4. 紀錄存在瀏覽器本機（不上傳、不外洩）

## 功能
- 自動分句（Intl.Segmenter）
- 逐句中文翻譯（可切繁中／簡中）
- 逐句朗讀：語速 0.5–1.3x、每句重複 1–3 次、音色可選
- 全部播放（自動捲動到當前句）
- 聽寫模式：遮住原文與翻譯，打完自動比對
- 星號難句 → 「只練星號」
- 最近 20 篇自動存本機，可回顧、可刪
